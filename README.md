# Descubra seu caminho no Front-End

## 1. Sobre o projeto

Projeto desenvolvido para a disciplina de Desenvolvimento Front-End para Web, referente ao Projeto 3 - Painel Interativo com JavaScript.

O objetivo é criar uma página interativa que permite ao visitante informar seu nome, escolher uma área de interesse e receber uma orientação personalizada.

## 2. Tema do projeto

Desenvolvimento de uma página educativa sobre as principais tecnologias do Front-End: HTML, CSS e JavaScript.

## 3. Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 4. Funcionalidades

- Campo para inserir o nome do visitante.
- Seleção entre HTML, CSS e JavaScript.
- Geração de orientações personalizadas.
- Validação do preenchimento do nome.
- Validação da área de interesse.
- Alternância entre tema claro e tema escuro.
- Layout responsivo para diferentes telas.

## 5. Organização dos arquivos

- index.html: estrutura da página.
- css/estilo.css: estilos e aparência visual.
- js/script.js: funcionalidades e interatividade.

## 6. Comandos JavaScript utilizados

- const e let: declaração de variáveis.
- document.getElementById(): localização dos elementos HTML.
- addEventListener(): identificação de eventos de clique.
- .value: leitura dos valores dos campos.
- .trim(): remoção de espaços em branco no início e no final do texto.
- if: verificação das condições.
- switch: identificação da área escolhida.
- Template strings: criação de mensagens personalizadas.
- .textContent: exibição das mensagens na página.
- .classList.toggle(): alternância entre os temas.
- .classList.add() e .classList.remove(): alteração das classes das mensagens.

## 7. Funcionamento

O visitante informa seu nome e seleciona uma área de interesse. Ao clicar no botão, o JavaScript verifica os dados preenchidos e apresenta uma orientação correspondente à opção escolhida.

Caso o nome esteja vazio ou nenhuma área seja selecionada, a página apresenta uma mensagem de orientação.

O botão de tema utiliza classList.toggle() para alternar entre o visual claro e escuro.
